# 2026-09-09 자동 답변 수신 체크포인트

## 이번 완료 범위

alpha.5: 명시적으로 보낸 채팅 한 건의 답변을 기존 인증 loopback 연결로
가져와 알림 담벼락 어댑터에 자동 전달한다. `plumbmate.read` 수동 복구 경로도
남아 있다. 자동 행동 실행, 장기 기억, 저장 분기 복원은 이번에 추가하지 않았다.

- `companion/turn_delivery.py`: 현재 요청 또는 같은 ID의 보관 요청으로
  binding/scene을 확인한 뒤 답변만 투영한다. 기억 패치·전체 기록·비용 정보는
  이 채널로 보내지 않는다. 실패는 고정된 시스템 사유 코드만 전달한다.
- `event_socket.py`: `turn_delivery_v1` 협상 후 `turn_poll`을 처리한다.
  이 읽기 요청은 게임 이벤트 큐를 채우지 않는다. 미지원 동반 앱은 수동 확인 유지.
- `game_mod/reply_delivery.py`: 단일 요청 감시, 현실 시간 간격, 만료,
  역할/장면 변경 검사를 담당한다. EA API·파일·모델 호출·스레드 없음.
- `commands.py`: 자동/수동 표시가 같은 요청 ID·역할·만료·중복 검사를 쓴다.
  알림 API는 게임 스레드에서 호출하고 제안된 행동은 실행하지 않는다.

## 자원 및 비용 경계

게임은 요청이 있을 때만 최대 1초에 한 번 조회하며, 대기 중 조회 한 건과
수신 답변 한 건만 보관한다. 서버는 인증 연결당 파일 조회를 초당 최대 4회로
제한한다(동시 연결 최대 4). 디렉터리/기억 전체 검색을 추가하지 않았다.

**1초는 이번 UX 설계 기본값이며 EA의 요구사항이나 확인된 엔진 주기가 아니다.**
새 턴 조회는 API/모델 생성 함수를 호출하지 않는다. 조회·연결 재시도와 유료
모델 재호출을 분리했다. 보낸 뒤 180초가 지나면 표시하지 않지만, 이미 시작한
유료 호출을 취소하거나 환불한다는 뜻은 아니다.

가족·로트·역할 변경, 참여 심의 로트 부재, bridge stop은 자동 감시를 종료한다.
손상된 답변/메타데이터, 미확인 ACK, 이전 턴 답변은 표시하지 않는다.
연결이 끊기면 전송 계층의 수신함을 비우며, 여전히 유효한 턴만 재조회한다.
UI 실패를 매 틱 재시도하지 않으며 캐릭터의 행동으로 위장하지 않는다.

## 검증

전체 회귀 **330개 통과**(14.616초). 기존 307개에 23개 추가.
스키마 export 일치와 `git diff --check`도 통과했다.

- 실제 companion 서버 + 비차단 게임 클라이언트 + 가짜 EA UI 연결 통합 테스트:
  여러 단어 한글/이모지 → mock 1회 호출 → 자동 알림 호출 → 수동 read 중복 방지.
- 게임 측 파일 읽기 함수를 실패하도록 바꿔도 위 자동 경로 통과.
- pending 상태의 1,000 tick에서 open/stat/mkdir/thread 생성을 금지한 검사 통과.
- 10,000번의 시간 진행 없는 callback에도 조회는 1회.
- 역할/로트 교체, 부재, 만료, 수동 선표시, 옛 요청/잘못된 scope 차단.
- UI 재진입/예외, 연결 단절, 미확인 ACK, 구버전 협상, 조회 과속 제한.
- 실패/완료 후 반복 조회에도 provider 호출은 늘어나지 않음.

이 검사는 **실제 게임 화면·한국어 IME·pause 중 Zone.update 빈도**를 증명하지 않는다.

## 빌드 및 로컬 설치

설치된 게임의 Python 3.7 런타임으로 production 모듈 **9개**를 빌드했다.
각 pyc magic을 게임과 대조한다. 진단 모드는 변경하지 않았다.

```text
dist/PlumbMate-alpha5.ts4script
SHA-256: 48040183c0e6feda2af84c4d0f903a1babb0ee44b82eaccd028dc37edafcee33
```

심즈 종료 상태를 확인한 뒤 실제 Mods의 기존 `00_PlumbMate_Test/PlumbMate.ts4script`
파일 하나만 교체했고 설치본의 SHA-256 일치를 확인했다.
기존 모드 백업은 `dist/install-backups/2026-09-09-alpha5/`에 보관했다.
Saves도 플레이 테스트 전 예방적으로 `dist/private-playtest-backups/2026-09-09/`
아래 복사했다. 두 폴더는 git에서 제외되며 게임 데이터나 RP 원문은 업로드하지 않는다.

동반 앱은 새 코드의 `run --provider mock --max-turns 8`로 재시작했다.
실제 설치 경로 대상 `doctor --connect` 결과: 전체 검사 성공, **api_calls: 0**.

## 아직 막힌 검증과 다음 순서

CUA에서 심즈를 열려 했으나 **Mac 잠금 상태이며 자동 해제할 수 없음**이 반환됐다.
잠금 해제가 필요하다. 따라서 이번에는 가족을 불러오거나 원본 세이브를 변경하지
않았으며, 실제 역할 선택창/한글 입력창/자동 알림은 아직 화면 검증 전이다.

잠금 해제 후:

1. 원본과 분리한 시험용 가족(최소 2심)에서 `plumbmate.setup` 역할 선택.
2. `plumbmate.chat` 창에 한글 직접 입력/붙여넣기/조합/취소/긴 입력 검사.
3. `plumbmate.read` 없이 자동 알림 수신 및 중복 read 차단 확인.
4. pause 상태, 역할/로트 전환, 동반 앱 중단/재연결의 실게임 스모크.
5. 이 경로가 통과한 뒤 콘솔 없는 메뉴 진입을 다음 작은 단위로 구현.

main 머지나 공개 배포는 하지 않는다. 이 버전을 자율 AI 파트너나 완성된
기억 시스템으로 소개해서는 안 된다.
