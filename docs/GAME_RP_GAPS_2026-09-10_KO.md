# 게임과 RP 표현 사이의 간극

## 이번 수정: 발화자 초상화

기존 `notify`는 `owner`만 전달했다. 설치본의 `UiDialogNotification.build_msg`
검사 결과, owner는 아이콘을 자동 보장하지 않으며 `icon_override`가 별도 경로다.
`distributor.shared_messages.IconInfoData(obj_instance=partner)`를 show_dialog에
전달하도록 alpha.7에 추가했다. 선택 중인 심이 아닌 검증된 partner 객체를 사용한다.

- 초상화는 EA의 기존 아이콘 경로를 사용한다. 이미지 생성/파일 복사/API 호출 없음.
- 아이콘 준비 실패 시 이름/본문만 표시한다. show_dialog 이후 재시도하지 않는다.
- 연결 실패·비용·대기 만료 안내는 캐릭터가 말한 것으로 보이지 않도록 시스템 제목을
  유지하고 자동으로 owner 초상화를 붙이지 않는다. 전용 시스템 그림은 아직 없다.
- 기본 역할/대화/자동 알림은 alpha.5에서 실게임 확인. **2026-09-11 alpha.7 초상화도 실게임 확인 완료.**
  플레이어 썸머를 선택한 상태에서 AI 트래비스의 얼굴/이름이 답변 알림에 표시됐고,
  수동 read 재호출은 이미 표시한 답변으로 차단됐다. 시스템 접수 알림에는 얼굴을 붙이지 않음.
- 회귀 341개 통과(14.776초). build magic 검사 통과.

## 몰입보다 우선되는 일관성

| 경계 | 현재 상태 | 다음 수용 기준 |
|---|---|---|
| 누가 말하는가 | player/partner 분리, 대사에 partner 초상화 추가 | 다른 심을 선택해도 얼굴/이름/발신 역할 일치 |
| 대사 vs 시스템 안내 | 실패/만료는 시스템, mock 명시 | 오류를 “지금 말하기 싫어” 같은 RP로 위장하지 않음 |
| 제안 vs 실제 행동 | 모든 행동 실행 비활성화 | 산책 제안을 완료된 산책/기억으로 승격하지 않음 |
| 모델이 아는 것 vs 실제 장면 | 현재는 작은 신원/가족 snapshot 중심 | 미관찰 행동·의상·감정을 본 것처럼 단정하지 않음 |
| 응답 생성 vs 표시 | request/binding/scene/180초 제한 | 여행·역할 변경 후 이전 장소 대사/초상화를 띄우지 않음 |
| 속마음 vs 대사 | 속마음 기능 미구현 | 내면 분석을 알림 본문으로 실수로 노출하지 않음 |
| 캐릭터 설정 vs 실제 심 | 역할은 세션 한정, 인격 프로필 미구현 | 재접속 시 임의의 심을 에이든으로 가정하지 않음 |
| 기록 vs 사실 | 모델 기억 patch 저장 금지, 영구 기억 미구현 | 관찰/플레이어 주장/해석을 분리하고 세이브 범위 검증 |
| 심리시/게임 행동 vs 한국어 글 | 텍스트만 연결, native 대화 동기화 없음 | 알림이 왔다고 두 심이 실제로 대화했다고 주장하지 않음 |

초상화는 “발화자가 누구인지”를 보완하지만 마지막 행의 행동 동기화까지
해결하지 않는다. 실행 결과가 검증되기 전에는 대사에서 행동 완료를 보장할 수 없다.
향후 출력 계약에 관찰 근거와 제안/대사 구분을 넣되, 단순 키워드 검사를
범용 환각 방지로 홍보하지 않는다.

## 작은 구현 순서

1. 초상화 실게임 확인 및 기존 중복/역할 변경/대기 만료 회귀.
2. 콘솔 없는 진입점, 수신자와 연결 상태를 한눈에 확인.
3. 제한된 관찰 snapshot + 출력의 제안/완료 구분. 실제 모델 품질 평가용 합성 사례.
4. 검증된 native 상호작용 실행/완료 이벤트에만 표현과 기록 연결.
5. 세션 기록 → 저장 계보 검증 후 지속 기억. 풍선은 별도 opt-in 표현 어댑터.

범용 감정 장식이나 대규모 UI 덮어쓰기를 이번 수정에 섞지 않는다.
