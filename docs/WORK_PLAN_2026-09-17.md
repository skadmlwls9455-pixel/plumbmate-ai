`commands.py` went from 748→687 lines. Reducing the total line count is not the goal. The new modules
can be checked without the game SDK, and the five conversation state globals are managed as one object.
The scene functions also access EA objects, so they are still called only on the game thread.
Existing commands and thin wrappers were kept for compatibility and gradual migration.

Full modularization is not finished. Bootstrap settings/lifecycle and conversation UI wiring logic
are still in commands. The next extractions proceed along the boundaries needed for feature wiring,
and empty layers or pass-through-only classes are not added merely to reduce line counts.
