# RFC-007 부분 명세 — 설치 안전성과 연결 진단

상태: 설계/수용 조건 + 일부 구현. Windows 실행 파일·연결 테스트 UI는 미구현이다. 파일 브리지 외에 loopback 소켓과 게임 틱 클라이언트가 구현되어 있다. 전달받은 타 제품의 장애 사례는 시험 후보이며, 이 문서가 해당 사례의 출처·발생률을 검증한 것은 아니다.

## 1. AV와 배포

- Defender 전체 해제, Mods/사용자 폴더 전체 예외, 관리자 권한 강제를 필수 설치 절차로 만들지 않는다.
- 공식 배포 URL, 서명 발급자, 릴리스 해시, 깨끗한 빌드 출처를 표시한다. 오탐 의심 시 격리 내역 확인과 제작자/보안업체의 검증·신고 절차를 먼저 안내한다. 검증 전 복원·예외를 자동 적용하지 않는다.
- 코드 서명·타임스탬프와 배포물 무결성 검증을 출시 체크리스트에 넣는다. 서명이 무해함을 보증하거나 SmartScreen 경고/AV 탐지를 없앤다고 설명하지 않는다. [Microsoft SmartScreen 설명](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation)은 서명과 파일/발급자 평판을 구분한다.
- 보안 예외는 기본 해결책이 아니다. Microsoft는 검사 예외가 보호 범위를 줄인다고 설명한다. [Microsoft 보안 앱 안내](https://support.microsoft.com/en-us/windows/virus-and-threat-protection-in-the-windows-security-app-1362f4cd-d71a-b52a-0b66-c2820032b65e)

## 2. 연결 테스트 버튼

`연결 테스트`는 API 호출·과금 없이 로컬 브리지만 검사한다. 외부 모델/API 검사는 별도 명시적 동작이다.

1. 동반 앱 실행 여부와 브리지 형식 확인.
2. 파일 브리지이면 경로·접근 가능 여부를 검사. 임시 쓰기 시험은 전용 테스트 파일만 사용한다.
3. 소켓 브리지 도입 시 loopback bind, 포트 점유, 도달성, 세션 인증, 프로토콜 호환성을 서로 다른 오류로 표시한다.
4. 제한 시간 내 응답하지 않으면 게임은 정상 자율행동으로 양보한다. UI는 재연결 상태와 진단 ID를 제공한다.

포트 충돌 시 소유 프로세스를 임의 종료하지 않는다. 고급 설정에서 사용하지 않는 포트로 변경하거나 자동 재할당하고 양쪽 설정을 확인한 뒤 재연결한다. 주소는 `127.0.0.1`/`::1`로 제한하며 `0.0.0.0` 바인딩으로 해결하지 않는다. 다른 앱의 listener를 PlumbMate로 오인하지 않도록 세션 인증이 필수다.

현재 구현은 IPv4 `127.0.0.1`과 고정/지속 포트 방식을 사용한다. CLI `listen`은 기존 설정 포트를 재사용하며 최초 기본값은 `47651`이다. 종료 시 endpoint 설정을 삭제하지 않고, 연결 여부는 소켓 상태로 판별한다. 충돌 시 오류를 표시하고 임의 포트 이동을 하지 않는다. `--port`로 의도적으로 변경하거나 토큰을 교체한 경우 게임에서 `plumbmate.bridge.start` 또는 게임 재시작으로 설정을 다시 읽는다. 토큰은 게임 시작 전에 준비하며, 준비되지 않았다면 게임 틱은 파일을 폴링하지 않고 설정 갱신을 기다린다. 게임 틱 내 파일 I/O와 게임 내부 백그라운드 리스너는 사용하지 않는다. UI 기반 양쪽 설정 갱신은 향후 구현이다.

## 3. 방화벽

루프백이 모든 보안 제품/정책에서 무조건 허용된다고 가정하지 않는다. 다만 연결 실패를 곧바로 방화벽 탓으로 단정하지 않고 프로세스·주소 계열·포트·인증부터 진단한다.

허용 규칙은 제품/정책별로 필요성이 확인된 경우에만 설명하고 사용자가 승인한다. 방화벽 전체 끄기, 공용망/원격 인바운드 전체 허용은 안내하지 않는다. 조직 관리 정책을 우회하지 않는다. 설치 프로그램은 자동으로 보안 규칙을 추가하지 않는다.

## 수용 조건

- AV 격리, 미서명/신규 서명, 앱 미실행, 포트 점유, 인증 실패, 프로토콜 불일치, IPv4/IPv6 불일치와 재시작을 구분해 표시한다.
- 연결 시험 중 API 비용 0, 게임 스레드 네트워크 대기 0, 다른 프로세스 종료 0.
- 진단 내보내기는 키·채팅·심 이름·개인 경로를 기본 제거하고 사용자 미리보기를 제공한다.
- Windows와 macOS는 각각 실제 배포 환경에서 검사한다. 현재 Mac 실험 결과를 Windows 호환 완료로 표시하지 않는다.
