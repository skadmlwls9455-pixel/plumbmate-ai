# PlumbMate AI — 포트폴리오 한 장 소개

## 한 줄 소개

**플레이어를 대신하지 않고 옆에서 함께 플레이하는, The Sims 4용 AI 2P 동반자.**

플레이어가 맡은 심과 AI가 맡은 심이 같은 세상에서 생활한다. AI 심은 현재
상황을 짧게 읽고 한국어로 의도를 설명하며, 플레이어가 허용한 행동만 게임에
요청한다.

## 해결하려는 문제

기존 AI 캐릭터 프로젝트는 대화가 재미있어도 실제 게임 상태와 분리되기 쉽고,
완전 자동 조작은 플레이어의 통제감과 저장 데이터 안전을 해칠 수 있다. 또한
화면을 계속 전송하는 방식은 개인정보와 API 비용 부담이 크다.

PlumbMate는 이 사이를 노린다.

- AI의 대화와 게임 행동 의도를 하나의 응답으로 만든다.
- AI가 먼저 “무엇을 왜 하고 싶은지” 말하고 플레이어가 승인한다.
- 임의 코드나 키보드 조작 대신 미리 허용한 행동 목록만 사용한다.
- 스크린샷이나 세이브 파일이 아니라 최소한의 구조화된 상태만 전달한다.

## 현재 구현된 MVP

```text
The Sims 4 → 작은 상태 JSON → 로컬 동반 앱 → AI 또는 무료 Mock
     ↑                                              ↓
     └──────── 검증된 한국어 답변 + 행동 제안 JSON ────────┘
```

- `plumbmate.chat <메시지>`로 에이든에게 말을 건다.
- 동반 앱이 짧은 한국어 답변과 행동 제안을 생성한다.
- `plumbmate.read`로 최신 답변을 확인한다.
- 네트워크 없이 실행되는 Mock 모드가 있어 데모와 테스트에 비용이 들지 않는다.
- 실제 게임 행동 실행은 아직 꺼져 있다. 다음 단계에서 승인 UI와 함께 연결한다.

## 토큰·비용 절약 설계

1. **상시 관찰 금지** — 매 프레임이 아니라 대화나 중요한 사건이 생길 때만 호출한다.
2. **상태 변화만 전송** — 첫 요청 뒤에는 달라진 욕구·관계·상황 필드만 보낸다.
3. **로컬 기억** — 최근 관계 사실은 기기에 작게 저장하고 필요한 일부만 프롬프트에 넣는다.
4. **짧은 구조화 응답** — 긴 자유문 대신 대사, 이유, 허용 행동을 JSON으로 받고 출력 상한을 둔다.
5. **안정된 프롬프트 앞부분** — 성격·안전 규칙을 고정해 프롬프트 캐시가 재사용되기 쉽게 한다.
6. **모델 라우팅** — 일상 대화는 저비용 모델, 드문 장기 스토리 설계만 상위 모델을 선택한다.
7. **중복 제거** — 같은 상태에서 반복된 저위험 반응은 로컬 캐시로 처리할 수 있게 설계한다.

현재 API 응답 상한은 220토큰이다. 모델 ID는 코드에 고정하지 않아 사용자가 비용과
성능을 직접 선택할 수 있다.

## 안전과 개인정보

- API 키는 `Mods` 폴더나 게임 파일에 넣지 않는다.
- 게임 프로세스는 인터넷에 직접 접속하지 않는다.
- 외부로 보낼 수 있는 항목은 공개된 JSON 스키마로 제한한다.
- 화면, 세이브, Tray, CC 파일은 전송하지 않는다.
- 모델 응답은 신뢰하지 않고 스키마와 행동 허용 목록으로 검사한다.
- 공개판은 전송 예시, 제공자, 보존 여부, 기록 삭제 기능을 첫 실행 전에 보여준다.

## 차별점

목표는 챗봇을 심 얼굴에 붙이는 것이 아니라 **설명 가능하고 승인 가능한 AI 공동
플레이어**를 만드는 것이다. 에이든은 말을 생성하는 NPC가 아니라, 플레이어와
합의하며 데이트·사진·집안일·관계 이벤트를 선택하는 두 번째 플레이어가 된다.

## 90초 데모 시나리오

1. 커플 심이 집에 있는 장면과 동반 앱의 Mock 모드를 보여준다.
2. “에이든, 오늘 둘이 사진 찍고 저녁 데이트할까?”라고 입력한다.
3. 에이든의 짧은 답변과 `suggest_only` 행동 제안을 확인한다.
4. 전송된 JSON에서 스크린샷 대신 작은 상태 변화만 들어간 것을 보여준다.
5. 다음 버전 목업으로 `승인 / 다른 제안 / 이번에는 내가 할게` 선택지를 보여준다.
