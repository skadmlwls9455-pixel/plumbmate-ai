# 2026-09-08 역할 계약·표시 안전장치 체크포인트

## 범위와 기준점

비용/성능/진단 체크포인트는 로컬 커밋 `7f697a1`에 보존했다(261개 테스트).
이번 작은 변경은 “현재 선택 심 = AI 화자”라는 잘못된 가정을 제거한다.
공개 배포, 유료 호출, 게임 저장/가족 변경, 실제 Mods 교체는 하지 않았다.
로컬 소스, 빌드 산출물, 실제 설치본, 원격 GitHub 반영을 구분한다.

## 이번에 코드로 들어간 것

| 경계 | 구현 | 남은 한계 |
|---|---|---|
| 게임 역할 | `role_binding.py`: 같은 가족의 서로 다른 두 SimInfo/ID를 명시적으로 지정 | 현재 로트 런타임만; 영속 설정/세이브 식별 아님 |
| 선택 화면 | `role_setup_ui.py`: 플레이어 → AI의 2단계 native picker, 취소/오래된 창/중복 콜백 방어 | 진입은 `plumbmate.setup` 콘솔; 실제 화면 검증 전 |
| 대화 계약 | `dialogue.py`: 미지정/동일/가족 밖/중복 ID/actor 불일치 거절 | 가족 12명까지, 두 심의 현재 로트 가용성만 제한적으로 확인 |
| 모델 입력 | 명시된 player/partner/message/recent_events만 투영; 두 역할 ID는 packing 중 보존 | AI 파트너의 세부 욕구/성격/기억은 아직 수집하지 않음 |
| 표시 | `plumbmate.read` → native notification, 실패 시 콘솔; 이미 표시한 요청은 재표시하지 않음 | 자동 전달/실제 한글 입력창은 미구현 |
| 늦은 답변 | 재지정·zone/household 객체 교체·심 제거/재생성·전송 후 180 실제 초 경과 시 표시 차단 | 이미 진행 중인 API 요청을 취소/환불하는 기능 아님 |
| 전송 | 같은 역할의 미표시 요청이 유효한 동안 추가 전송 차단; failed 상태는 새 전송 허용 | 여러 창/여러 동반 앱의 일반 요청 소유권은 후속 과제 |

심 하나인 가족에서는 역할을 임의 생성/복제하지 않고 안내만 한다. 선택 심을
바꿔도 역할은 바뀌지 않는다. 파트너가 현재 로트에 없으면 대화를 보류한다.
이 검사는 래빗홀/비활성 가족의 완전한 생명주기 처리가 아니다.

`actor`는 이제 **지정한 플레이어**다. `roles`에는 player/partner ID와 임의의
binding/scene 토큰이 있다. scene 토큰은 런타임 표시 울타리이지 save_scope나
save_commit의 증거가 아니다. 객체 교체가 확인되면 안전하게 재설정한다.

요청 shape의 `roles`는 구형 파일에 구체적인 거절 이유를 제공하기 위해 선택
필드지만, 엔진과 공급자는 모델 실행 전에 반드시 요구한다. 프로토콜 표기는
아직 미출시 `0.1`이다. **alpha.3 게임/동반 앱을 함께 사용해야 한다.** 구형
동반 앱은 새 필드를 거절하며 새 동반 앱은 역할 없는 구형 요청을 격리한다.

## 검증과 증거

- 역할 미지정/동일 심/가족 밖/잘못된 actor/중복 ID/범위 초과 요청에서 공급자
  호출 및 세션 시도 차감이 없는지 검사했다.
- 한국어 다단어 요청, 선택 심 변경, 한 가족 내 역할 재지정, 로트 전환,
  중복 chat/read, 만료 응답, 파트너 부재를 게임 API 스텁으로 검사했다.
- 선택창은 실제 설치본 `1.127.41.1230` 바이트코드의 심볼/인자 순서만 읽어 확인했다.
  `UiSimPicker.__init__`의 첫 인자가 `sim_filter`이므로 소유 심은 `owner=`로
  전달한다. 위치 인자 실수를 통과시키지 않는 스텁으로 회귀 검사한다.
- notification/picker가 실제 화면에 뜨는지, 직접 IME 한글 입력이 되는지는
  아직 확인하지 않았다. 화면 도구의 상태 조회가 시간 초과되어 게임을 조작하지 않았다.
- 합성 500턴: pack+실제 모델 문맥 투영 중앙값 0.380ms, p95 0.430ms,
  평균 936→517 UTF-8 bytes. 한 번의 로컬 측정; 토큰·전체 프롬프트·요금 절감률이 아니다.
- 최종 전체 회귀 **281개 통과, 11.925초**. schema export와 `git diff --check` 통과.
- 실제 게임 Python 3.7로 production 모듈 6개를 컴파일하고 설치본 bytecode
  magic `420d0d0a` 일치를 검사했다. `dist/PlumbMate-alpha3.ts4script` SHA-256:
  `0232ac8fcbfff868ba87c4e2dcb2dc1b544640de106d57de4bb84a48eb4f750b`.
  이 산출물은 아직 실제 Mods에 설치하지 않았다. 원격 CI 결과도 아니다.

정상 테스트 답변에는 `[연결 테스트·mock]`을 붙인다. 로컬 연결 성공을 실제
AI 파트너나 자율행동 성공처럼 소개하지 않는다. 선택 API 심볼 존재/빌드
성공/스텁 테스트가 실제 화면 검증을 대신하지 않는다.
